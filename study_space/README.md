# HUFLIT StudySpace 🎧📚

Không gian học tập tương tác nhập vai (Immersive Study Environment) được phát triển độc lập, mang lại trải nghiệm tập trung tối đa cho học tập và làm việc.

## 🌟 Tính năng nổi bật

- **50+ Bối cảnh Video 4K & Ảnh chất lượng cao**: Nhiều chủ đề đa dạng từ anime, quán cafe mưa, ban đêm, thư viện, vũ trụ, thiên nhiên...
- **Bộ trộn âm thanh môi trường (Sound Mixer)**: 20 âm thanh tự nhiên chất lượng cao (mưa, sấm chớp, sóng biển, gió, tiếng lật sách, lò sưởi, quán cà phê...).
- **Trình phát nhạc Lo-fi / Jazz / Relax**: Tích hợp danh sách nhạc thư giãn và hỗ trợ nhúng YouTube/Spotify.
- **Đồng hồ Pomodoro thông minh**: Thiết lập thời gian tập trung, nghỉ ngắn, nghỉ dài cùng chuông báo Web Audio chimes đa dạng (chuông cổ điển, chuông chùa Zen, tiếng chim hót).
- **Kanban Tasks & To-do list**: Quản lý nhiệm vụ trực quan, kéo thả, gắn deadline và theo dõi tiến độ hoàn thành.
- **Ghi chú nhanh (Quick Notes)**: Soạn thảo văn bản phong phú với Markdown, lưu trữ cục bộ tự động (Local Storage).
- **Zen Mode**: Ẩn mọi widget gây xao nhãng chỉ bằng 1 nút bấm để tập trung cao độ.

## 🚀 Hướng dẫn cài đặt & Chạy ứng dụng

```bash
# Cài đặt dependencies
npm install

# Chạy môi trường phát triển (mặc định cổng 3001)
npm run dev

# Chạy kiểm thử Unit Tests
npm test

# Build ứng dụng cho môi trường Production
npm run build
```
